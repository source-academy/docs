# Publications

Publications about Source Academy, its languages, and the tools built with it, by members of the community. All entries are in one BibTeX file: [source-academy.bib](/source-academy.bib).

## Book

- Harold Abelson and Gerald Jay Sussman with Julie Sussman; adapted to JavaScript by Martin Henz and Tobias Wrigstad with Julie Sussman. _Structure and Interpretation of Computer Programs, JavaScript Edition_. MIT Press, April 2022. ISBN 9780262543231. [Read online](https://sourceacademy.org/sicpjs), [PDF](https://sicp.sourceacademy.org/sicpjs.pdf).

## How to cite

Cite the publication that matches what you used:

| You used                               | Cite                                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------------------ |
| the Source Academy platform            | _Source Academy: A Web-based Environment for Learning Programming with SICP_ (SIGCSE 2023) |
| the Source languages (Source §1 to §4) | _Shrinking JavaScript for CS1_ (SPLASH-E 2021)                                             |
| the stepper                            | _A Stepper for a Functional JavaScript Sublanguage_ (SPLASH-E 2021)                        |
| the textbook                           | _Structure and Interpretation of Computer Programs, JavaScript Edition_                    |
| Pie and proof education                | _More Pie for the Little Typer_ (SPLASH-E 2026)                                            |

Every entry, ready for BibTeX: [source-academy.bib](/source-academy.bib).

Missing a publication? Open a pull request that adds it to `app/public/source-academy.bib` and to this page.
